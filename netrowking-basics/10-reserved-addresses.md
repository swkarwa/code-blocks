# Reserved Addresses

Each subnet reserves:
1. Network address
2. Broadcast address

Example:

```text
192.168.1.0/24
```

---

## Network Address

```text
192.168.1.0
```

All host bits are `0`.

---

## Broadcast Address

```text
192.168.1.255
```

All host bits are `1`.

---

## Usable Range

```text
192.168.1.1 - 192.168.1.254
```
