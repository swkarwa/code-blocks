# IPv4

## Structure of IPv4

IPv4 contains 4 octets separated by `.`

Example:

```text
192.168.1.10
```

Each octet:
- ranges from `0-255`
- contains 8 bits

---

## Network and Host Portion

An IP address contains:
1. Network portion
2. Host portion

Example:

```text
172.16.0.1
```

- Network portion => `172.16`
- Host portion => `0.1`

---

## Communication Within Same Network

Devices in same network:

```text
172.16.0.1
172.16.0.2
172.16.0.3
```

can communicate directly.

Devices in different networks:

```text
172.16.0.1
172.17.0.1
```

require a router.
